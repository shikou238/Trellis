# UI シーン DSL リファレンス

`ui/*.ui`（シーン）の書き方の一覧。実装は `crates/dsl/src/parser.rs`（構文）と `crates/uikit/src/scene.rs`（意味）。
計測の設定ファイル（menu-proto の `ui/tasks.ui`）の書き方は最後の節。

---

## 1. 基本

- 全体は S式。`;;` から行末まではコメント。
- **数値を書ける場所**には、次の4つのどれでも書ける。

  | 書き方 | 例 |
  |---|---|
  | リテラル | `260`、`0.5`、`-12`（`-` は数字に密着させる） |
  | 名前 | `item_w`、`time`、`open`（状態名） |
  | `{中置式}` | `{item_w + padding * 2}` |
  | `(関数 引数...)` | `(smoothstep 0 open_time state_time)` |

### `{}` の中のルール
| やりたいこと | 書き方 | 例 |
|---|---|---|
| 四則演算・比較 | 中置で書く | `{width / 2 - 120}` |
| 関数を呼ぶ | `( )` は**S式の関数呼び出し** | `{90 + 60 * (sin {time * 3})}` |
| 結合の順番を変える | `( )` ではなく **`{ }` を入れ子にする** | `{{item_h + gap} * 4}` |
| 関数の引数に演算を書く | 引数を `{ }` で囲む | `(clamp {state_time / open_time} 0 1)` |
| 負の数を引数にする | `-` を数字に密着させる | `(wrap -1 4)` |
| 式の結果の符号を反転する | 単項の `-` | `{-(abs x)}` |

- 関数の引数に書けるのは **リテラル / 名前 / `{中置式}` / `(関数呼び出し)`** だけ。`(max 1 - 2)` のように演算子を裸で書くとエラーになる。
- 旧い書き方 `{sin(x)}`、`{max(a, b)}` はエラー（新しい書き方を案内するメッセージが出る）。
- **名前に `-` を含められる**ので、`{a-b}` は名前 `a-b` と読まれる。引き算は `{a - b}` と空白を入れる（名前は `item_w` のように snake_case を推奨）。

## 2. 演算子（`{}` の中）

結果が真偽になるものは **1（真）/ 0（偽）** を返す。0 以外は真として扱われる。

| 優先度 | 演算子 | 意味 | 例 → 結果 |
|---|---|---|---|
| 高 | `-x` | 符号反転 | `{-3}` → -3 |
| 高 | `!x` | 否定（0 なら 1、それ以外は 0） | `{!open}` → open にいなければ 1 |
| 中 | `*` `/` | 乗算・除算 | `{2 + 3 * 4}` → 14 |
| 低 | `+` `-` | 加算・減算（左結合） | `{10 - 3 - 2}` → 5 |
| 最低 | `==` `!=` `<` `<=` `>` `>=` | 比較 | `{1 + 1 == 2}` → 1 |

「かつ」は `*`、「または」は `max` で書ける: `{page * {screen == 0}}`（page にいて、かつ screen が 0）。

---

## 3. 組み込みの値

| 名前 | 意味 |
|---|---|
| `time` | シーンが動き始めてからの秒数（リロードしても続きから進む） |
| `state_time` | 今の状態に入ってからの秒数（`goto` で 0 に戻る） |
| `width` / `height` | ウィンドウの大きさ（論理ピクセル） |
| `pi` | 円周率 |
| 状態名（例: `open`） | その状態にいれば 1、いなければ 0 |

---

## 4. 関数

| 関数 | 引数 | 意味 | 例 | 結果 |
|---|---|---|---|---|
| `sin` | x | 正弦（x はラジアン） | `(sin {pi / 2})` | 1 |
| `cos` | x | 余弦（x はラジアン） | `(cos 0)` | 1 |
| `abs` | x | 絶対値 | `(abs -3)` | 3 |
| `floor` | x | 切り捨て（小さい方の整数） | `(floor -0.5)` | -1 |
| `min` | a b | 小さい方 | `(min 3 5)` | 3 |
| `max` | a b | 大きい方 | `(max 3 5)` | 5 |
| `clamp` | x lo hi | x を lo〜hi に収める | `(clamp 12 0 10)` | 10 |
| `lerp` | a b t | a から b へ t の割合で補間（t は 0〜1 に収めない） | `(lerp 0 100 0.25)` | 25 |
| `wrap` | x n | 0〜n の範囲に折り返す（負の数も正しく） | `(wrap -1 4)` | 3 |
| `select` | 条件 a b | 条件が真なら a、偽なら b | `(select {cursor == 0} 255 120)` | cursor が 0 なら 255 |
| `smoothstep` | 端0 端1 x | x が 端0→端1 と進む間に、0→1 へなめらかに変化（範囲外は 0 か 1） | `(smoothstep 0 0.2 0.1)` | 0.5 |

### よく使う形

| やりたいこと | 書き方 |
|---|---|
| 状態に入ってから `open_time` 秒かけて 0→1 | `(def appear (smoothstep 0 open_time state_time))` |
| 0→1 の値で位置を動かす | `(def x (lerp width 60 appear))` |
| 一定の速さで点滅（透明度 30〜150） | `(rgba 255 255 255 {90 + 60 * (sin {time * blink_speed})})` |
| カーソルを 0〜3 で循環させる | `(set cursor (wrap {cursor + 1} 4))` |
| 状態と変数で表示を切り替える | `(visible {page * {screen == 0}})` |
| 条件で色を変える | `(rgb (select {cursor == 0} 255 120) 40 60)` |

## 5. フォーム一覧

### 定義
| フォーム | 意味 | 例 |
|---|---|---|
| `(defparam 名前 既定値 (型 最小 最大 刻み))` | 調整用の値。インスペクタにスライダーとして出る。型は `Int` / `Float`。`_` または省略は「指定なし」。既定値はリテラルのみ | `(defparam item_w 260 (Float 100 400 _))` |
| `(var 名前 初期値)` | 実行時の変数。`set` で変える。リロードしても値を引き継ぐ。初期値はリテラルのみ | `(var cursor 0)` |
| `(def 名前 値)` | 毎フレーム計算される名前付きの値。**def から別の def を使うときは、使うより前に定義する** | `(def top {height / 2 - 120})` |

`defparam` / `var` / 状態名はファイル内のどこからでも参照できる。名前の重複・組み込みの値と同じ名前はエラー。

### 状態（ステートマシン）
```lisp
(state 名前
  (on トリガー [(when 条件)] [(set 変数 値)]... [(emit 名前 値...)]... [(goto 状態)])
  ...)
```
- 最初に書いた `state` が初期状態。
- 1つの入力につき、今の状態の `on` を上から見て**最初に当てはまった1つだけ**を実行する。

| トリガー | 意味 |
|---|---|
| `(press 操作)` | 操作のボタンが押された |
| `(release 操作)` | 操作のボタンが離された |
| `(after 秒)` | この状態に入ってから指定秒数たった（`goto` 必須） |

操作の名前: `menu` `up` `down` `left` `right` `confirm` `cancel`（キー配置は [menu-proto/DESIGN.md](../menu-proto/DESIGN.md) §4）

| 節 | 意味 |
|---|---|
| `(when 条件)` | 条件が真のときだけこの遷移を使う |
| `(set 変数 値)` | 変数を変える（複数の `set` は、すべて遷移前の値で計算してから代入する） |
| `(emit 名前 値...)` | 意味のある通知を出す。計測の完了判定に使う（例: `(emit opened 1)`） |
| `(goto 状態)` | 状態を移る（`state_time` が 0 に戻る）。なければ状態はそのまま |

### 描画
| フォーム | 意味 | 例 |
|---|---|---|
| `(background 色)` | 背景色。省略するとカーソル位置の色 | `(background (rgb 24 24 32))` |
| `(rect x y 幅 高さ 色 [オプション]...)` | 矩形。x y は左上（論理ピクセル） | `(rect 60 top item_w item_h (rgb 230 40 60))` |

| `rect` のオプション | 意味 |
|---|---|
| `(rotate 度)` | 矩形の中心まわりに回転 |
| `(visible 条件)` | 条件が偽なら描かない |

| 色 | 意味 |
|---|---|
| `(rgb r g b)` | 0〜255 |
| `(rgba r g b a)` | 0〜255（a も 0〜255） |

## 6. 計測の設定（`ui/tasks.ui`）

| フォーム | 意味 | 例 |
|---|---|---|
| `(scenes "パス"...)` | 交互に試すシーン | `(scenes "ui/menu_a.ui" "ui/menu_b.ui")` |
| `(trials 回数)` | 試行の回数（全シーンの合計） | `(trials 20)` |
| `(timeout 秒)` | 1 試行の制限時間 | `(timeout 10)` |
| `(wait 秒)` | 試行の間の待ち時間 | `(wait 0.5)` |
| `(task "表示する文字" (通知の名前 値...))` | 課題。シーンが同じ通知を `emit` したら完了、名前が同じで値が違えば誤操作 | `(task "青" (opened 1))` |

## 7. よくあるエラー

| メッセージ | 原因と直し方 |
|---|---|
| `function calls are written in S-expression form` | `{sin(x)}` → `{(sin x)}` |
| ``( ) is a function call (f a b); to group an expression use { }`` | `{}` の中でかっこを結合のために使った。`{(a + b) * 2}` → `{{a + b} * 2}` |
| `expected a number, name, {expression}, or (call) as an argument` | 関数の引数に演算子を裸で書いた。`(max a 1 - 2)` → `(max a {1 - 2})` のように `{}` で囲む |
| `unknown name a-b` | 名前に `-` が続いた。`{a-b}` → `{a - b}` |
| `takes N argument(s), got M` | 関数の引数の数が違う（§4 の表を参照） |
| `unknown name` | 名前の打ち間違い、または def を使うより後で定義した |

エラーはログとインスペクタに `ファイル:行:列` つきで出る。エラーの間も、直前に読み込めたシーンのまま動き続ける。
